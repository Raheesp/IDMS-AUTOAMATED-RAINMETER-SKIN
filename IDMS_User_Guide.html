How to use the IDMS report panel

Everything the panel can do — downloading, scheduling, emailing, and managing reports — explained end to end. Written for anyone using it for the first time, and useful as a lookup later.

01 Overview

The IDMS panel picks any combination of the 30 IDMS reports, a date range, and gets them out of the portal — either immediately, on a repeating schedule, or straight into an email. It always runs unattended once you've asked it to: closing the panel doesn't cancel a schedule or a scheduled email, because both are registered as real Windows Scheduled Tasks.

Four things the panel can do, all starting from the same report checklist:

Download now Schedule a download Email a report Schedule an email

Downloads and emails both use the exact same reports list, date range, and CREATE DUMP setting — you check what you want once, then decide whether to download it, schedule it, email it, or schedule the email.

02 Opening the panel

The IDMS panel lives under the PORTAL DATA bar on your desktop. Click the IDMS ▾ dropdown in the top-right of that bar to expand the full report list and controls. Click it again to collapse it.

💡
Tip

The PORTAL DATA bar itself shows live Booking/Docket/Enquiry counts and has its own RUN NOW button — that's a separate, always-on data refresh and isn't part of the IDMS panel described in this guide.

03 Selecting reports

Click any report name to check it — [ ] becomes [x]. Reports are listed in two columns, 30 in total. Use ALL to check every report, NONE to clear the selection.

Hover any report name to see a tooltip with its label and, once you've run REFRESH AVAILABILITY at least once, the actual date range that report has data for in the portal.

💡
Tip

Your selection is shared across DOWNLOAD, SCHEDULE TASK, and EMAIL. Check reports once, then choose what to do with them.

04 Choosing a date range

The DATE RANGE row controls what window of data each selected report pulls, for both immediate downloads and schedules.

OptionWhat it does
AS-ISEach report's own default view, dates left untouched. Fastest option — downloads immediately with whatever the portal shows by default.
TODAYSets every date-driven report's range to just today.
THIS MONTH1st of the current month through today.
LAST MONTH1st through the last day of last calendar month.
LAST 2 MONTHS1st of the month two months ago through today.
CUSTOM…Opens a small text file in Notepad with FROM= and TO= (format YYYY-MM-DD). Edit, save, close — the preview line updates automatically next time you look at the panel.

A live preview line under the pills always shows exactly what range will be used, e.g. "Will use 2026-07-01 → 2026-07-27".

💡
Reports without a date filter

Some reports (Stock Report, Invoice Pending, Priority Booking, and a few others) have no date-range filter at all — the date range pills are simply ignored for those and they always download their current full view.

05 Downloading right now

  1. Check the report(s) you want. The status line under the report list confirms how many are selected.
  2. Pick a date range (or leave it on AS-IS).
  3. Click DOWNLOAD. The panel logs in and downloads each selected report in turn, showing live progress ("Downloading 2/5: Docket Report...").

When it finishes, the status line turns green with a result summary, or red with a clear reason if something failed. Click OPEN FOLDER any time to jump straight to where the files land.

💡
Filenames always overwrite

Every save replaces the existing file of the same name — a report never accumulates (1), (2) copies. Downloading the same report twice in a row just refreshes it in place.

06 Bulk historical archive (CREATE DUMP)

CREATE DUMP is a different mode for date-driven reports: instead of one date range, it walks month by month from a start month through the current month and downloads each month separately, then optionally merges them.

ControlWhat it does
BULK DUMP / CREATE DUMP: ON/OFFToggles the mode. When ON, the DATE RANGE pills above are ignored entirely.
DUMP FROM: monthClick to edit the starting month in Notepad (FROM=YYYY-MM). Defaults to January of the current year.
COMBINE FILESMerges every month into a single file per report.
KEEP SEPARATEKeeps one file per month, in a subfolder named after the report.

With CREATE DUMP on, click DOWNLOAD exactly as normal — it works the same way, it just fetches many months instead of one range.

⚠️
Not supported by EMAIL

You can schedule a CREATE DUMP download, but you cannot email a CREATE DUMP selection — the EMAIL button will refuse and tell you to switch CREATE DUMP off first.

💡
Automatic fallback

If a particular month genuinely has no data, the tool automatically substitutes the closest available range instead of failing outright, and writes a plain-text note (0_USED_WIDER_DATE_RANGE.txt) in the output folder listing exactly which reports were substituted and why.

07 Scheduling a download

Turns your current report selection into a real, repeating Windows Scheduled Task — it keeps running even if this panel (or Rainmeter itself) is closed.

How to create one

  1. Select your reports (and date range / CREATE DUMP settings) as usual.
  2. Click SCHEDULE TASK. A small text file opens in Notepad.
  3. Fill in the fields (all explained below), then save the file and close Notepad.
  4. Click CONFIRM SCHEDULE — the button changes label after step 2, and this second click is what actually registers the task. Nothing happens from saving Notepad alone; you must click this.
⚠️
Always click CONFIRM

The button intentionally will not auto-detect that you've finished editing — closing Notepad by itself does nothing. This is deliberate: registering a schedule is permanent enough that it needs an explicit second click, not a guess.

The draft file, field by field

; --- IDMS SCHEDULE TASK -----------------------------------------
NAME=              optional — your own label; blank = auto-named from reports/repeat
TIME=09:00         24-hour HH:MM
DATE=              optional override, YYYY-MM-DD; blank = next occurrence of TIME=
PATH=              optional custom save folder; blank = normal Downloads folder
REPEAT=once        once / daily / weekly / monthly / interval
DAYS=              weekly only — e.g. Mon,Wed,Fri
EVERY=             interval only — minutes between runs (5 minimum)
MONTHS=1            monthly only — every how many months
DATEFOLDER=off      off / today / yesterday

REPEAT modes explained

REPEAT=BehaviourNeeds
onceFires one time at TIME= (or DATE=+TIME=), then removes itself automatically after a successful run.—
dailyFires every day at TIME=.—
weeklyFires only on the days listed, at TIME=.DAYS=Mon,Wed,Fri
monthlyFires every N months, on the day of month from DATE= (or today's day-of-month if DATE= is blank), at TIME=.MONTHS=
intervalFires repeatedly all day, every N minutes, starting at TIME=.EVERY= (5+ minutes)

DATE= works with every mode, not just monthly — set it whenever you want an exact one-off date instead of "the next time TIME= comes around." For monthly, it doubles as the day-of-month the schedule repeats on (day 29–31 simply skips shorter months, same as picking it in Windows' own Task Scheduler).

DATEFOLDER — dated subfolders

Only meaningful when PATH= is set. When on, each run creates a dated subfolder inside PATH and saves into that instead of directly into PATH:

DATEFOLDER=Example, run on 27-Jul-2026
off (default)PATH\ — no subfolder
todayPATH\27-07-2026\
yesterdayPATH\26-07-2026\

The date is worked out fresh every time the schedule actually fires — a daily or weekly schedule with DATEFOLDER=today automatically gets a brand-new dated folder each time, with no extra setup.

✔️
Multiple reports, one schedule

Every report you had checked when you clicked SCHEDULE TASK is saved into that one schedule, and they all land in the exact same PATH (and the same dated subfolder, if DATEFOLDER is on) every time it runs.

💡
Many independent schedules

There's no limit on how many schedules you create. Each one is fully independent — different reports, different times, different paths — so you can have a daily 9am download of one report and a weekly Friday download of five others running side by side.

08 Viewing all schedules

Click SCHEDULES to open a plain-text summary of every scheduled download you've created — reports, save path, repeat pattern, next run, and the result of its last run.

==============================================================
1. IDMS Scheduled - Booking Report - Daily 0900 (a1b2c3)
==============================================================
   Repeats:   Daily
   Reports:   booking
   Save to:   C:\Reports\Daily  (dated subfolder created each run - today's date)
   Next run:  07/28/2026 09:00:00
   Last run:  07/27/2026 09:00:04  (succeeded)

These are real Windows Scheduled Tasks, so you can also see (and enable/disable/delete) them directly in Task Scheduler → Task Scheduler Library → IDMS Scheduled — though it's usually easier to use the panel's own DELETE TASK button instead.

09 Emailing reports

Sends your selected reports as attachments via Outlook — either right away, or on the same kind of repeating schedule as downloads.

⚠️
EMAIL sends what's already downloaded

It does not trigger a fresh download of its own — it attaches whatever file is currently sitting in the Downloads folder for each checked report. Click DOWNLOAD first (or have a schedule already deliver the files) before emailing.

How to send

  1. Select your reports (make sure each one has already been downloaded at least once).
  2. Click EMAIL. A small text file opens in Notepad.
  3. Fill in TO/SUBJECT/BODY and TIME (see below), save, close Notepad.
  4. Click CONFIRM EMAIL — same two-step reasoning as SCHEDULE TASK: nothing sends until this explicit click.
; --- IDMS SEND EMAIL -----------------------------------------
TO=                required — one or more addresses, comma-separated
CC=                optional, comma-separated
SUBJECT=           optional; blank = "IDMS DATA" — used exactly as typed, nothing auto-generated
BODY=              optional message; use | to start a new paragraph
TIME=NOW           NOW = send immediately, once. Otherwise 24-hour HH:MM to schedule
DATE=              optional (ignored when TIME=NOW) — same as SCHEDULE TASK's DATE=
REPEAT=once        ignored when TIME=NOW; otherwise once/daily/weekly/monthly/interval
DAYS=
EVERY=
MONTHS=1

TIME=NOW is the important switch: leave it as NOW for an immediate one-time send with no Windows Scheduled Task involved at all. Set a real HH:MM and a REPEAT= to schedule it instead — the exact same vocabulary as scheduling a download (daily/weekly/monthly/interval, DAYS=/EVERY=/MONTHS=, and a DATE= override) applies here too.

What actually happens when it sends

  1. Outlook opens automatically (reusing it if it's already running, or launching and later closing it if it wasn't).
  2. A message is composed with your subject/body, the A.M. Motors letterhead, and every attached report file that could be found.
  3. It's sent, and the panel waits to confirm it actually left the Outbox before reporting success.
💡
Multiple attachments, one email

Every report checked when you clicked EMAIL goes into that one message as separate attachments — send five reports and the recipient gets one email with five files, not five emails.

💡
A report with no downloaded file yet

If one of your checked reports was never actually downloaded, it's skipped rather than failing the whole send — the result message tells you exactly which ones were skipped and why.

10 Viewing all scheduled emails

Click EMAILS for the same kind of summary as SCHEDULES, but for email deliveries — subject, recipients, reports, repeat pattern, next send, and last result. These live under Task Scheduler → Task Scheduler Library → IDMS Email Scheduled — a separate folder from download schedules, so the two never get mixed up.

11 Deleting or changing a schedule/email

  1. Open SCHEDULES or EMAILS and copy the exact task name of the one you want to remove — e.g. IDMS Scheduled - Booking Report - Daily 0900 (a1b2c3).
  2. Click DELETE TASK. A small text file opens.
  3. Paste the name into TASKNAME=, and set TYPE=schedule or TYPE=email depending on which list it came from.
  4. Save, close Notepad, then click CONFIRM DELETE.
TASKNAME=IDMS Scheduled - Booking Report - Daily 0900 (a1b2c3)
TYPE=schedule       schedule = SCHEDULES list, email = EMAILS list

This permanently unregisters the real Windows Scheduled Task and deletes its saved settings — it can't be undone.

⚠️
To change something instead of removing it

There's no in-place edit — delete the old one, then create a fresh one with SCHEDULE TASK or EMAIL using the new time, reports, path, or recipients. This keeps every schedule's settings simple, frozen text files rather than something that can drift out of sync.

12 Reading the status messages

Every row has its own status line underneath it, colour-coded the same way throughout the panel:

ColourMeaning
Grey / dimIdle — nothing running, just telling you what will happen if you click the button.
Orange / accentIn progress — logging in, downloading, sending, or registering.
GreenSucceeded.
Amber-orange (email only)Partially succeeded — some reports were skipped because they weren't downloaded yet; the message explains which.
RedFailed — the message explains why.

13 Where your files go

  • No custom PATH= — everything saves to the normal Downloads folder (the same place OPEN FOLDER takes you).
  • PATH= set, DATEFOLDER=off — saves straight into that folder.
  • PATH= set, DATEFOLDER=today/yesterday — saves into a DD-MM-YYYY subfolder inside that folder, created automatically.
  • CREATE DUMP + KEEP SEPARATE — one subfolder per report, one file per month inside it.

Filenames are always the same for the same report and always overwrite the previous version — nothing ever piles up as numbered duplicates.

14 Troubleshooting

"login did not succeed — password may have changed or portal unreachable"

The portal login failed. This is retried automatically a few times before this message ever appears, so it usually means either the saved password is out of date or the portal itself was briefly unavailable. Click UPDATE PASSWORD to check/update the saved credentials, or simply try again in a minute if the portal was just slow.

"another IDMS download is already running — try again shortly"

Two downloads tried to run at the same moment (for example a schedule fired while you clicked DOWNLOAD yourself). This is a safety lock, not an error with your data — nothing was corrupted, just wait a few seconds and try again.

"no downloaded files found for: … — click DOWNLOAD first"

You tried to email reports that have never actually been downloaded. Click DOWNLOAD for them first, then EMAIL again.

"PATH is not writable: …"

The custom folder you typed either doesn't exist and couldn't be created, or you don't have permission to write to it. Try a folder under your own Documents or Desktop.

"a task named '…' already exists"

Extremely rare — every generated task name includes a unique id. If you ever see this, wait a second and re-create the schedule (a fresh id will be generated).

"no schedule task named '…' found" (DELETE TASK)

The TASKNAME= didn't match anything exactly. Re-copy it from the SCHEDULES or EMAILS summary — it must match character-for-character, including the (xxxxxx) id at the end.

Notepad opened but nothing seems to happen after I save

This is expected — saving the file alone never triggers anything. You always need the second click: CONFIRM SCHEDULE, CONFIRM EMAIL, or CONFIRM DELETE, whichever button you started with.
